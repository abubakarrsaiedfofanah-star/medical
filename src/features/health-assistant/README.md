# SAIED Health Assistant

The assistant should:
- collect symptoms in plain language;
- help patients organize difficult-to-explain health concerns;
- translate/simplify patient language;
- create a clinician-ready summary;
- detect possible emergency red flags and immediately escalate;
- recommend which SAIED portal/service to use (doctor, nurse, clinic, hospital, pharmacy, lab);
- never independently diagnose or prescribe.

Use a self-hosted model through `ai-service/`.
