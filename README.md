# SAIED V2 — Medical Healthcare Platform

A red-themed, responsive healthcare platform foundation covering the public site and role-based portals.

Stack:
- React + TypeScript + Vite
- CSS
- React Router
- PWA
- Supabase/PostgreSQL-ready
- QR receipt-ready architecture

Portals:
Patient, Doctor, Nurse, Pharmacist, Pharmacy, Clinic, Hospital, Laboratory, Admin.

This package is a complete UI/application foundation and module structure. Real clinical deployment requires jurisdiction-specific privacy/security review, provider licensing verification, payment integration, and clinical workflow validation before production use.
